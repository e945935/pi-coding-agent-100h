# Code Review Prompt Template

請用資深工程師角度 review 指定的程式碼或變更。

## Review 重點

請檢查：

1. 正確性
2. 可讀性
3. 維護性
4. 安全性
5. 效能
6. 測試覆蓋
7. 是否符合專案既有風格

## 輸出格式

請用以下格式輸出：

```markdown
# Code Review 結果

## 總結

一句話摘要整體品質。

## 必修

- [檔案/位置] 問題與建議

## 建議

- [檔案/位置] 問題與建議

## 可忽略

- [檔案/位置] 小建議

## 建議測試

- 建議執行或新增的測試
```

請使用繁體中文，台灣習慣用語。
