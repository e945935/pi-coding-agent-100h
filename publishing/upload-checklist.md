# Google Play Books / Kobo 上架資料檢查表

## 共用資料

- [ ] EPUB 可通過 EPUBCheck
- [ ] 封面比例與解析度符合平台要求
- [ ] 書名、作者、語言、出版者一致
- [ ] 書籍簡介已完成
- [ ] 關鍵字不含誤導或侵權品牌宣稱
- [ ] 已確認版權頁與授權內容
- [ ] 已填寫 ISBN；若尚未申請，先使用平台提供的識別碼流程
- [ ] 已測試目錄、連結、程式碼區塊與中文字型顯示
- [ ] 已在手機、平板、桌面閱讀器各預覽一次

## Google Play Books Partner Center

- [ ] 建立書籍與基本書目資料
- [ ] 上傳 EPUB
- [ ] 上傳封面或確認 EPUB 內含封面
- [ ] 填寫書籍簡介、作者、語言與分類
- [ ] 設定銷售地區、價格與稅務資料
- [ ] 確認內容分級與預覽比例
- [ ] 送出審核並保留版本紀錄

## Kobo Writing Life

- [ ] 建立新書
- [ ] 填寫書名、副標題、作者與簡介
- [ ] 選擇語言、分類與關鍵字
- [ ] 上傳 EPUB 與封面
- [ ] 設定版權、價格、地區與發行日期
- [ ] 使用 Kobo 預覽器檢查排版
- [ ] 發布前確認 DRM 與授權選項

## 發布前人工檢查

- [ ] 第一頁不是空白頁
- [ ] 封面文字在縮圖下仍可辨識
- [ ] 目錄可點擊並能返回正文
- [ ] 程式碼不會超出頁面或被截斷
- [ ] 連結可點擊且沒有 localhost / 個人路徑
- [ ] 書中沒有 API key、token 或私人檔案路徑
- [ ] README 的 GitHub 連結可正常開啟

> 平台規格與介面可能變更，實際上傳前請再查閱 Google Play Books 與 Kobo Writing Life 的最新官方說明。
