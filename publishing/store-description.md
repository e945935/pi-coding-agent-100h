# 商店簡介

> 上架時請將「100 小時」理解為完整課程規模；一般讀者依本書內容約 60 小時可完成核心學習。

## 短版簡介

《Pi Coding Agent 100 小時實戰教材》以繁體中文、台灣習慣用語，帶讀者從 Pi Coding Agent 基礎使用一路學到工作流客製化、Extensions 開發，以及 SDK、RPC、JSON 系統整合。

## 長版簡介

這不是只介紹指令的工具手冊，而是一套以實作為核心的完整學習教材。

讀者會從安裝、登入、模型選擇與第一個專案分析任務開始，逐步學會管理 session、建立 `AGENTS.md`、設計 Prompt Templates 與 Skills，並進一步開發 TypeScript Extensions，加入自訂工具、指令與安全防護。最後再透過 SDK、RPC 與 JSON mode，把 Pi Coding Agent 整合到自己的 CLI、自動化流程或其他應用程式。

本書包含：

- 100 小時分階段課程規劃
- 可直接操作的 sample project
- Windows、PowerShell、Git Bash 指令說明
- Provider 與模型選擇建議
- 安全檢查表與常見問題排除
- 作業、評量與總整專題範本
- 給 Claude Code、Codex、Cursor、Aider 等使用者的遷移指南

適合想把 AI coding agent 導入個人開發、團隊工作流或系統整合的工程師與技術主管。
