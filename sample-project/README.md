# Sample Project

這是一個給 Pi Coding Agent 100 小時教材使用的簡單 Node.js 練習專案。

## 功能

提供兩個簡單函式：

- `add(a, b)`：兩數相加
- `isEmail(value)`：檢查字串是否像 email

## 安裝

```bash
npm install
```

## 測試

```bash
npm test
```

## Lint

```bash
npm run lint
```

## Build

```bash
npm run build
```

## 給學員的練習

可以請 Pi：

1. 摘要專案
2. 找出可用指令
3. 建立 `AGENTS.md`
4. 幫 `isEmail` 補更多測試
5. 改善錯誤處理或型別定義
